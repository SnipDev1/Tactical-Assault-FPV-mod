[**English Version of README**](README.md)

Полноценный мод для тактического VR-шутера **Tactical Assault VR** (Unity 6 / IL2CPP x64), полностью поддерживающий **Windows 10/11** и **Linux / SteamOS (Proton / WiVRn)**. Добавляет в игру комплект из **трех ударных FPV-дронов камикадзе**, тактический пульт-планшет с цифровым экраном и телеметрией OSD, реалистичную физику полета, плавный оптический зум до 10x, наклон камеры вниз на 90° и полную интеграцию в оружейную комнату (Armory) и разгрузочный жилет оператора.

---

## Основные возможности

* **Флот из трех ударных дронов**: Оператор переносит до 3 дронов-камикадзе в подсумках для гранат/утилит.
* **Циклическое переключение**: Мгновенное переключение видеопотока и управления между дронами нажатием на правый стик (`R-Stick Click`), с индивидуальным учетом заряда аккумуляторов и автоматическим пропуском уничтоженных дронов.
* **Тактический планшет управления и OSD**: Видеопоток в реальном времени (512x320), центральное прицельное перекрестие `[ + ]`, телеметрия в стиле Betaflight/DJI (высота, скорость, напряжение 6S аккумулятора, угол наклона камеры, индикатор текущего зума и статус взведения боевой части).
* **Плавный оптический зум от 1.0x до 10.0x**: Непрерывное зуммирование без ступеней с плавным сужением угла обзора от широкого (115° FOV) до сверхточного телескопического режима (11.5° FOV).
* **Наклон камеры вниз до 90 градусов (Nadir)**: Полноценное управление наклоном камеры от крейсерского угла (+28°) до строго вертикального направления вниз (-90°) для вертикальной разведки и крутого пикирования на цели.
* **Плавная регулировка высоты**: Непрерывное интегрирование высоты полета (`_holdAltitude += climbInput * climbSpeed * dt`) устраняет любые рывки при отпускании стика.
* **Компактный 7-9" FPV-фрейм (0.8x)**: Уменьшенный до 80% легкий ударный корпус с удлиненными агрессивными лопастями и контактной боевой частью.
* **Процедурный синтезатор звука моторов**: Фазово-непрерывный акустический синтез писка бесколлекторных регуляторов ESC (2640 и 3300 Гц) и рассекания воздуха 3-лопастными пропеллерами (720 и 1440 Гц).
* **Включение по триггеру и безопасность**: Дроны требуют нажатия на триггер при извлечении из подсумка для подачи питания. Детонация от удара заблокирована, пока дрон в руках бойца или в подсумке.
* **Смягченная взрывная волна**: Осколочный урон и радиус поражения остаются смертельными, а физический импульс отбрасывания тел уменьшен с 700 до 90 Н·с для реалистичного падения ragdoll.
* **Магнитная доводка в подсумки**: Удобный возврат планшета и дронов в слоты разгрузки при приближении рук к жилету.
* **Изоляция оружейных слотов**: Кобуры пистолетов и слоты для автоматов защищены от случайного попадания гранат или планшетов.

## Управление в VR

### Левый контроллер (Полет и боевая часть)

| Элемент управления | Действие |
| :--- | :--- |
| **Левый стик Y** | Высота / Вертикальный подъем и спуск |
| **Левый стик X** | Рыскание / Разворот по курсу (Yaw) |
| **Кнопка X (Primary)** | Активация управления / возврат к пилотированию / дизарм моторов |
| **Кнопка Y (Secondary)** | Взведение / снятие с боевого взвода (`[ ! WARHEAD ARMED ! ]` / Safe) |
| **Левый триггер (LT)** | Наклон камеры вниз (вплоть до `-90°` вертикально в землю) |

### Правый контроллер (Маневрирование, оптика и камера)

| Элемент управления | Действие |
| :--- | :--- |
| **Правый стик Y** | Тангаж (Pitch — вперед / назад) |
| **Правый стик X** | Крен (Roll — боковое скольжение) |
| **Клик правого стика** | Переключение активного дрона (`1` $\to$ `2` $\to$ `3` $\to$ `1`) |
| **Кнопка A (Зажатие)** | Плавное приближение зума (до `10.0X`) |
| **Кнопка B (Зажатие)** | Плавное отдаление зума (до `1.0X`) |
| **Правый триггер (RT)** | Наклон камеры вверх (до `+75°` в небо) |

### Физические взаимодействия руками

* **Взять / Убрать**: Возьмите планшет с груди или дрон из гранатного подсумка рукой (кнопка хвата Grip). Для возврата поднесите предмет обратно к жилету.
* **Включение питания**: Достав дрон из подсумка, нажмите один раз на указательный триггер — загорится светодиод питания, и дрон активируется в планшете.
* **Аварийный спавн (Клавиатура)**: Нажатие клавиши `F8` спавнит свежий комплект дрона и планшета перед глазами игрока.

## Установка

### Требования

* Установленная через Steam игра **Tactical Assault VR**.
* Установленный загрузчик модов **MelonLoader (v0.6.x или новее)** для Unity 6 / IL2CPP x64:
  * [Официальный инсталлятор MelonLoader для Windows и Linux](https://github.com/LavaGang/MelonLoader.Installer/releases).

---

### Установка на Windows

#### Автоматическая (в 1 клик)
1. Дважды кликните по файлу `install.bat` (или запустите `.\install.ps1` в PowerShell).
2. Скрипт сам найдет установку игры на дисках `C:\`, `D:\` или `E:\`, соберет проект и скопирует файл `TacticalAssaultFPV.dll` в директорию `Tactical Assault VR\Mods\`.

#### Ручная установка
1. Скачайте файл `TacticalAssaultFPV.dll` из вкладки [Releases](https://github.com/dmitry/tactical-assault-fpv/releases).
2. Скопируйте `TacticalAssaultFPV.dll` в папку:
   ```
   C:\Program Files (x86)\Steam\steamapps\common\Tactical Assault VR\Mods\
   ```
3. Запустите игру обычным образом через Steam в VR! Никаких дополнительных параметров запуска на Windows вводить не требуется.

---

### Установка на Linux / Steam Deck

#### Автоматическая установка
Запустите скрипт установки в терминале:
```bash
./install.sh "/путь/к/Tactical Assault VR"
```
*(Если путь не указан, скрипт использует стандартную директорию Steam)*.

#### Параметры запуска для Linux / Proton / WiVRn
В библиотеке Steam нажмите правой кнопкой на **Tactical Assault VR** $\to$ **Свойства** $\to$ **Параметры запуска** и укажите:
```bash
WINEDLLOVERRIDES="version=n,b" %command%
```
*(При использовании WiVRn через Flatpak добавьте: `PRESSURE_VESSEL_IMPORT_OPENXR_1_RUNTIMES=1 PRESSURE_VESSEL_FILESYSTEMS_RW=/var/lib/flatpak/app/io.github.wivrn.wivrn`)*.

## Сборка из исходников

### Требования к среде

* [.NET 6.0 SDK](https://dotnet.microsoft.com/download/dotnet/6.0) (для сборки самого мода)
* [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (для запуска тестов)

### Команды сборки и тестирования

```bash
# Сборка на Windows (PowerShell / CMD)
dotnet build src\TacticalAssaultFPV\TacticalAssaultFPV.csproj -c Release

# Сборка на Linux / macOS (Bash)
dotnet build src/TacticalAssaultFPV/TacticalAssaultFPV.csproj -c Release

# Запуск полного набора из 219 стресс-тестов (Кроссплатформенно)
dotnet run --project tests/TacticalAssaultFPV.StressTests/TacticalAssaultFPV.StressTests.csproj -c Release
```

## Архитектура проекта

```
├── src/
│   └── TacticalAssaultFPV/
│       ├── Config/ModConfig.cs               # Настройки (скорости, разрешения, углы)
│       ├── Controller/RCTablet.cs           # Логика планшета, OSD, обработка VR-ввода
│       ├── Drone/
│       │   ├── DroneCameraRig.cs            # Камера FPV, зум 10x, наклон 90°
│       │   ├── DroneExplosive.cs            # Детонация при ударе, поражение осколками
│       │   ├── DroneFactory.cs              # Сборка компактной модели (0.8x), лопасти
│       │   ├── DroneMotorAudio.cs           # Процедурный синтез звука моторов
│       │   └── DronePhysics.cs              # Плавная физика полета и удержание высоты
│       ├── Loadout/
│       │   ├── ArmoryEquipButtonTrigger.cs  # Кнопка EQUIP FPV в оружейной комнате
│       │   └── FPVLoadoutIntegration.cs     # Фильтры подсумков, синхронизация 3 дронов
│       ├── Diagnostics.cs                   # Встроенный автотест в игре
│       └── ModMain.cs                       # Инициализация мода и безопасность в мультиплеере
├── tests/
│   ├── TacticalAssaultFPV.StressTests/      # Автономный набор из 219 тестов
│   ├── ChallengerM4/                        # Проверка на утечки памяти и сбои
│   └── ChallengerM4R2/                      # Стресс-тесты динамики полета Монте-Карло
├── install.bat / install.ps1                # Скрипты автоустановки на Windows
├── install.sh                               # Скрипт автоматического развертывания на Linux
├── uninstall.bat / uninstall.ps1            # Скрипты удаления на Windows
├── uninstall.sh                             # Скрипт удаления на Linux
└── LICENSE                                  # Лицензия MIT
```
